Task 10 · Animations

🎬 Animations in BookList UI

All animations used in the BookList interface — showing where each animation appears and how it works.

1 · Page Load Fade In

fadeInDown · fadeInUp · CSS animation
Header slides in from top on page load
Where: Every page transition. Type: CSS fadeInDown/Up, 0.3–0.5s ease.

2 · Logo Float Animation

floatUp · infinite · CSS keyframe
📚
Logo gently floats up and down in header
Where: BookList logo icon in header and home hero. Type: CSS translateY loop, 3s ease-in-out infinite.

3 · Skeleton Loading Screen

shimmer · loading placeholder
Shown while book list data loads
Where: My Books page — shown briefly while the book table renders. Type: CSS shimmer gradient animation.

4 · Progress Bar Animation

progressFill · animated width
Reading Progress70%
Stats page reading progress bar
Where: Home stats, Stats page, toolbar. Type: CSS width animation from 0% to target, 2s ease-out.

5 · Loading Spinner

spin · rotation · loading state
Shown during data fetch / save actions
Where: When adding a book, saving settings, or loading data. Type: CSS rotate + bounce keyframe.

6 · Toast Notifications

toastSlide · opacity + translateY
✅ "Dune" added to your list!
Appears after every user action
Where: After every action — add, remove, toggle, save. Type: CSS opacity + translateY slide-up, 0.2s ease. Auto-dismisses.

7 · Button Hover & Ripple

ripple · hover · transform
Click to see ripple effect
Where: All buttons. Type: CSS hover transition + JS ripple (scale + opacity) on click.

8 · Table Row Hover & Select

background transition · border-left
The Great Gatsby — Fiction ✓ Read
Dune — Sci-Fi ⏳ To Read
Sapiens — Non-Fiction ✓ Read
Hover to highlight · Click to select
Where: My Books table rows. Type: CSS background-color transition + blue left border on selection.

9 · Status Badge Toggle

scale · popIn · color transition
✓ Read← Click to toggle
Click status badge to switch Read/To Read
Where: Every book row badge. Type: popIn keyframe (scale 0.7→1.05→1) + color/background transition.

10 · Navigation Tab Highlight

navPop · background transition
🏠 Home📋 My Books📊 Stats
Click tabs to see transition
Where: Header navigation tabs. Type: CSS background transition + navPop keyframe on activation.

11 · Card Hover Lift

translateY · box-shadow · hover
📚 Hover over me!
Stat cards and book grid cards
Where: Home stat cards, book grid cards. Type: CSS translateY(-4px) + box-shadow increase on hover.

12 · Animated Background Gradient

bgShift · gradient animation
BookList — Your Reading Tracker
Used as accent on hero areas
Where: App splash and hero section. Type: CSS background-position animation, 4s ease infinite.

13 · Typing / Cursor Animation

typeCursor · blink · input affordance
Search by title or author|
Blinking cursor in search/input fields
Where: Search bar and focused input fields. Type: CSS opacity blink, 0.7s step-end infinite.

14 · Wizard Step Progress

background transition · pulse
✓
2
3
Multi-step form wizard in Forms page
Where: Add Book Wizard. Completed steps turn green, active pulses blue, future grey.

15 · Modal Pop-In

popIn · scale + opacity
✓ popIn animation
Remove book confirmation modal
Where: Remove book modal, success banners. Type: popIn — scale(0.7)→scale(1.05)→scale(1), 0.2s ease.
